# Bundled data

`cities.csv` is derived from the [GeoNames](https://www.geonames.org/) `cities15000` dump, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It keeps every capital and every city of 1,000,000 people or more, plus Austin, Texas. Regenerate it with `python3 tools/cities.py path/to/cities15000.txt` and commit the output.
